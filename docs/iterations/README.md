# Iteration notes

Use this directory for short notes about meaningful development slices.

Copy this shape into a dated or issue-named Markdown file:

```markdown
# Iteration: <short name>

## Outcome

What user-visible behavior changed?

## Item/action seam

Which domain items, capabilities, actions, or projections changed?

## Evidence

- Automated:
- Manual:
- Unverified:

## Drift check

What was deliberately left out, and what follow-up remains separate?
```

Do not use iteration notes to turn an unfinished feature into a release claim.
